BitOasis API token

Create it on the BitOasis website: Settings › Security › Token Management. Allow trading and balance access only, never withdrawals. Keep AED in your BitOasis wallet for the live budget.

Binance API key

Create it in Binance: Account › API Management. Tick only Enable Spot & Margin Trading, never Withdrawals, and restrict it to your server's IP.

Safety limits (both accounts)

Percentages are of each account's budget. If today's losses reach the daily limit, the bot stops buying until tomorrow. If total losses reach the max, the bot stops completely until you reset it.
